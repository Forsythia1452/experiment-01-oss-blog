# Issue：按标签和阅读时长生成相关推荐

## 用户故事

作为读者，我希望在读完文章后看到同主题内容和预计阅读时长，以便决定下一篇阅读什么。

## 数据来源与边界

- 数据来源：Ghost 公开内容数据，由主题 `get` 助手在服务端查询。
- 匹配规则：相同主标签、排除当前文章、最多 3 篇。
- 阅读时长：Ghost `reading_time` 助手，基于字数与图片估算。
- 隐私：只查询已发布公开内容，不读取用户画像，不将管理密钥放入前端。
- 非目标：不做协同过滤、不收集读者行为、不修改 Ghost 核心。

## 验收条件

- [x] 有相同主标签时返回不超过 3 篇。
- [x] 结果不包含当前文章。
- [x] 每张卡片显示标题、标签、摘要和阅读时长。
- [x] 无同标签文章、无标签、查询失败均有可理解的状态。
- [x] 宽屏显示三列，窄屏显示单列，无水平滚动。
- [x] `npm test` 和 `npm run test:theme` 通过。
