## 失败用例与修复

首次 `gscan .` 报告 2 个错误和 3 个警告：缺少 `.kg-width-wide` / `.kg-width-full`、自定义字体变量、主题关键词和页面标题开关支持。修复后执行 `npm run check`：4 个单元测试全部通过，GScan 输出 `Your theme is compatible with Ghost 6.x`。

## 已知限制

会员登录采用 Ghost 邮件 magic link。当前是本地开发邮件配置；现场演示前应使用可控测试邮箱或本地邮件接收器，不应把真实凭据写入仓库。
