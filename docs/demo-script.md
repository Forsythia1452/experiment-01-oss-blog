# 5-10 分钟 Live Demo 脚本

1. **0:00-0:45 项目目标**：打开首页，说明这是基于 Ghost 6.45.0 的可注册、可写作、可评论、可搜索个人博客。
2. **0:45-1:30 基线与差异**：展示 `docs/baseline.md`，强调未修改 Ghost 核心，变更位于独立主题。
3. **1:30-2:20 会员与搜索**：点击登录；使用测试邮箱完成 magic link；搜索“可复现工程”，进入目标文章；再搜索不存在词展示无结果。
4. **2:20-3:30 文章与标签**：进入 `/ghost/`，新建一篇带“Web工程”标签的文章，发布后返回前台验证。
5. **3:30-4:20 评论和权限**：会员在文章底部评论；退出后再点评论，展示必须登录的错误状态。
6. **4:20-5:30 自主功能**：打开 `Ghost 主题目录结构速查`，演示 2 张同标签相关卡片、阅读时长和无标签失败状态。
7. **5:30-6:30 核心代码**：打开 `post.hbs`，解释 `primary_tag` 筛选、`id:-{{id}}` 排除和 `reading_time`。
8. **6:30-7:30 测试**：执行 `./scripts/Test-Lab.ps1`，展示 4/4 单元测试、GScan 和 HTTP 检查。
9. **7:30-8:30 恢复与 Git**：展示脱敏导出、主题 ZIP、提交图和 PR 自审记录。
10. **8:30-9:00 取舍**：说明未修改核心便于升级；局限是当前相关性只使用主标签，未使用行为数据。
